# Куда доберёшься — Москва

Зона досягаемости по Москве: куда можно добраться пешком и на общественном транспорте за заданное время.
Нажмите на карту или перетащите точку — зона пересчитывается в браузере.

## Как это считается
- Остановки и маршруты метро, МЦК, МЦД, трамваев, троллейбусов и автобусов — из OpenStreetMap (Overpass).
- Расписаний нет: ожидание = половина типового интервала для вида транспорта, скорости заданы по виду транспорта.
  Это оценка «будний день, днём».
- Пешком — только по улицам, дорожкам, мостам и переходам: граф собран из карты (OpenStreetMap), реки, каналы и железные дороги — препятствия, пересекать их можно лишь там, где есть мост или переход. Закрашивается сама улица и узкая полоса вокруг неё, пустые «дыры» внутри зоны (дворы, парки) заполняются, реки остаются пустыми. Вне зоны, где есть граф улиц (Москва + северо-запад: Красногорск, Опалиха, Нахабино и др.), считается по прямой с запасом ×1,3 — но не через реки и железные дороги (мосты проходимы).
- Параметры сверены с Яндекс Картами на нескольких поездках по метро (разница в пределах 3–7 минут).

## Запуск
```
npm install
npm run dev
```
Данные собираются так:
- транспорт: `./fetchall2.sh && node scripts/build-network.mjs raw2 public/network.json`
- улицы и препятствия (нужны `moscow.pmtiles` и граница города `raw/boundary.json`):
  `MARGIN_M=1500 node scripts/build-streets.mjs moscow.pmtiles build-out && cp build-out/*.gz public/`
- метро на карте: `./fetch-metro.sh && node scripts/build-metro.mjs raw/metro.json public/metro.json`

## Публикация на GitHub Pages
`./deploy.sh` — собирает сайт и заливает в ветку `gh-pages` (нужен токен в `~/.gh-token`).

Данные: © участники OpenStreetMap (ODbL). Карта: OpenFreeMap, OpenMapTiles.

## Статистика и режимы
- **Зона** — статистика по выбранной точке: доля Москвы, число станций и остановок, график площади по минутам (считается в фоновом Web Worker).
- **Удалённость от центра** — время в пути от Красной площади до каждой точки; гистограмма долей территории.
- **Доступность** — тепловая карта «сколько км² можно охватить за T минут из этой точки» и рейтинг лучших и худших мест. Данные предрасчитаны: `node scripts/build-access.mjs public public/access.json` (≈ 15 минут на 11 потоках).
- **Районы** — 132 района и поселения Москвы (границы из OpenStreetMap): раскраска по показателю (охват за N минут, время до центра, пешком до метро, плотность остановок и улиц, площадь), рейтинги, сравнение округов и карточка района. Данные: `./fetch-districts.sh && node scripts/build-districts.mjs public raw public/districts.json`.
- **Шкала цвета** в «Доступности» и «Районах» идёт от минимума до максимума без «среза»; середину шкалы можно привязать к среднему арифметическому, геометрическому или квадратическому.
